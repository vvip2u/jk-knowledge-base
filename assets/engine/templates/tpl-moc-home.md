## 一、这套库按「知识资产的角色」分类

不是按主题分，而是按**内容在知识生产过程中扮演的角色**分。同一件事的不同层次，落在不同目录：

```
原始信息 → 认知加工 → 实验验证 → 资产沉淀 → 项目应用 → 复盘迭代
```

它要能回答六个问题：**我知道什么 / 我如何理解 / 我验证过什么 / 我创造了什么 / 我正在做什么 / 下次如何做得更好**。

**关键约定：一份内容只有一个主要存放位置**，但可以拥有多个标签、双向链接和索引入口——
不要把同一份文件复制到五个目录。

## 八、日常怎么用

1. 新东西一律先扔收件箱，**每周清一次**，判断它属于哪个角色；
2. 原始资料不加工，加工后的数据另开文件放「研究与洞察」；
3. 你的判断不是事实——放进「思考与假设」，验证过的才升级到「知识与模型」；
4. 项目目录只放计划、任务、工作文件和**资产索引**，不复制资产本体；
5. 半年复审一次（`review: 180d`），过期内容进归档目录，不删。
